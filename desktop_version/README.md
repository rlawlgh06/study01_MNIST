# 손글씨 숫자 인식기 (MNIST + PyTorch)

> 브라우저에서 돌아가는 웹 버전은 `../web_version/` 에 있습니다.

마우스로 직접 숫자를 써서 입력하면, 학습된 CNN 모델이 그 숫자가 0~9 중 무엇인지 인식합니다.

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `model.py` | CNN 모델 구조 정의 (합성곱 2층 + 완전연결 2층) |
| `train.py` | MNIST 데이터로 학습하고 `mnist_cnn.pt`로 가중치 저장 |
| `draw_predict.py` | 마우스로 손글씨를 입력해 인식하는 그림판 프로그램 |
| `아이콘_만들기.py` | 바로가기용 아이콘(`아이콘.ico`) 생성 |
| `바로가기_만들기.ps1` | 바탕 화면 · 시작 메뉴 바로가기 생성 |
| `mnist_cnn.pt` | 학습된 가중치 파일 (학습 후 생성됨) |
| `아이콘.ico` | 앱 아이콘 (생성됨) |
| `data/` | MNIST 데이터셋이 자동으로 내려받아지는 폴더 |

## 준비

```bash
py -m pip install --index-url https://download.pytorch.org/whl/cpu torch torchvision
```

> **`python` 이 아니라 `py` 를 쓰세요.** 이 PC의 `python` 은 Microsoft Store 스텁이라
> torch 가 설치되어 있지 않습니다.

## 1) 학습하기

```bash
py train.py
```

- 기본 3 에폭 학습하며, 매 에폭마다 평가 정확도를 출력합니다.
- 학습이 끝나면 `mnist_cnn.pt` 파일이 만들어집니다.
- 에폭 수를 바꾸려면: `py train.py --에폭 5`

## 2) 손글씨로 인식하기

```bash
py draw_predict.py
```

- 왼쪽 그림판에 마우스를 끌어 숫자 하나를 **크게** 씁니다.
- 마우스를 떼면 자동으로 인식되어, 오른쪽에 예측 숫자와 0~9 확률 막대가 표시됩니다.
- `Enter` 키: 다시 인식 / `C` 키: 지우기

## 3) 바탕 화면 바로가기 만들기

```powershell
py 아이콘_만들기.py                                             # 아이콘.ico 생성
powershell -ExecutionPolicy Bypass -File .\바로가기_만들기.ps1   # 바로가기 생성
```

- 바탕 화면에 **손글씨 숫자 인식기** 바로가기가 만들어집니다.
- `python.exe` 가 아니라 `pythonw.exe` 로 실행하므로 **검은 콘솔 창이 뜨지 않습니다.**
- 아이콘은 `아이콘.ico` 로 지정됩니다.
- 바로가기와 앱에 같은 앱 식별자(AppUserModelID)를 넣어, 작업 표시줄에 고정한 아이콘과
  실행 중인 창이 하나로 묶입니다.
- 시작 메뉴에도 등록되어 윈도우 검색으로 바로 찾을 수 있습니다.

**작업 표시줄에 고정하는 방법**: 바탕 화면 바로가기에서 마우스 오른쪽 클릭 →
(윈도우 11이면 "추가 옵션 표시" →) **작업 표시줄에 고정**.
또는 앱을 실행한 뒤 작업 표시줄의 아이콘을 오른쪽 클릭 → 작업 표시줄에 고정.

## 인식이 잘 되게 하는 요령

입력 그림은 MNIST 학습 데이터와 같은 형태로 자동 변환됩니다.
(밝기 반전 → 글씨 영역만 잘라내기 → 20x20으로 축소 → 무게중심을 28x28 중앙에 배치 → 정규화)

그래도 다음을 지키면 정확도가 더 높아집니다.

- 숫자 한 개만, 그림판을 가득 채울 정도로 크게 쓰기
- 너무 얇거나 흐리게 쓰지 않기 (붓 두께는 `draw_predict.py`의 `붓두께` 값으로 조절 가능)
