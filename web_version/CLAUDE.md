# web_version — 순수 자바스크립트 추론

데스크톱이 학습한 가중치로 브라우저에서 추론만 합니다. GitHub Pages 에 정적 배포됩니다.

상위 규칙은 `../CLAUDE.md` 를 먼저 보세요.

## 지켜야 하는 제약

1. **외부 라이브러리를 쓰지 않습니다.** npm 패키지, CDN 스크립트, 빌드 도구, 번들러 전부
   해당합니다. `package.json` 은 Node 가 `테스트/*.js` 를 ES 모듈로 읽게 하는 표시일 뿐이며
   `dependencies` 를 갖지 않습니다.
2. **경로는 전부 상대 경로입니다.** Pages 는 `https://<사용자>.github.io/<저장소>/` 하위에
   서빙되므로 선행 `/` 를 쓰면 배포된 사이트에서 깨집니다. `model/weights.json` 처럼 씁니다.
3. **ES 모듈**(`<script type="module">`)을 씁니다.
4. **한글 식별자**와 설명 주석을 씁니다 (기존 코드 관례).

## 실행

`fetch` 와 ES 모듈 모두 `file://` 에서 막히므로 HTTP 서버가 필요합니다.

```bash
py -m http.server 8000
# http://localhost:8000/                 앱
# http://localhost:8000/자가진단.html     검증
```

## 모듈 경계

| 파일 | 역할 | DOM |
| --- | --- | --- |
| `js/리샘플.js` | PIL LANCZOS 호환 크기 변환 | 없음 |
| `js/전처리.js` | 회색조 바이트 → 28×28 정규화 배열 | 없음 |
| `js/모델.js` | CNN 순전파 · 소프트맥스 | 없음 |
| `js/가중치.js` | `weights.json`+`bin` → 텐서 사전, 검증 | 없음 (`fetch`) |
| `js/그림판.js` | 포인터 입력 → 캔버스 두 장 | 있음 |
| `js/화면.js` | 결과 렌더링 (넘겨받은 요소 안에만) | 있음 |
| `js/앱.js` | 조립 · 초기화 · 오류 처리 | 있음 |

계산 모듈은 DOM 을 건드리지 않습니다. 그래야 검사에서 그대로 호출할 수 있습니다.
이 경계를 무너뜨리지 마세요.

## 고친 뒤에는 반드시 자가진단을 통과시킵니다

```bash
py -m http.server 8000     # http://localhost:8000/자가진단.html
```

총평이 초록색 `전체 통과` 여야 합니다. 검사는 `테스트/고정표본.json` 과 대조하는데,
이 고정표본은 **데스크톱의 실제 함수**가 만든 것입니다. 현재 7개 검사 모음
(`검사틀_검사`, `리샘플_검사`, `전처리_검사`, `가중치_검사`, `모델_검사`, `그림판_검사`, `화면_검사`)
총 68건이 모두 통과합니다.

검사 모음을 추가하려면 `테스트/<이름>_검사.js` 에 `만들기(...)` 를 내보내고
`테스트/전체검사.js` 의 `모음들` 배열에 넣습니다.

## 전처리를 건드릴 때

`js/전처리.js` 와 `js/리샘플.js` 는 `../desktop_version/draw_predict.py` 의
`MNIST_형식으로_변환` 을 **단계·반올림까지** 따라 한 것입니다. 특히 조심할 곳:

- **파이썬 `round()` 는 은행가 반올림입니다** (`round(12.5) == 12`). JS `Math.round` 를
  쓰면 크기가 1픽셀 어긋납니다. `파이썬_반올림` 을 쓰세요.
- **중간값을 uint8 로 유지합니다.** float 로 들고 가면 무게중심이 미세하게 달라져
  이동량 반올림이 1픽셀 튑니다.
- **모델용 캔버스를 흰색으로 먼저 채웁니다.** 캔버스 기본값은 투명이고 투명 화소의
  RGB 는 0 이라, 채우지 않으면 배경이 검게 읽혀 전처리가 통째로 뒤집힙니다.

`js/리샘플.js` 의 LANCZOS 재구현은 현재 PIL 출력과 **바이트 단위로 완전히 일치**하며
허용오차를 두지 않았습니다. 앞으로 오차가 생기면 여기(그리고 상위 `../CLAUDE.md`)에
얼마나 허용했는지를 반드시 남기세요.

한쪽만 고치지 말고 데스크톱과 함께 보세요. 고쳤다면:

```bash
py tools/고정표본_만들기.py     # 기대값 다시 만들기
```
